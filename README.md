# vinext-starter

Galina Chumak's product design portfolio, built with
[vinext](https://github.com/cloudflare/vinext).

## Prerequisites

- Node.js `>=22.13.0`

## Quick Start

```bash
npm install
npm run dev
npm run build
```

This starter does not use `wrangler.jsonc`.

## Project Structure

- edit site code under `app/`
- `app/` contains pages, components, hooks, and global styles
- `public/` contains the media used by the portfolio
- `.openai/hosting.json` contains Sites hosting configuration

## Useful Commands

- `npm run dev`: start local development
- `npm run build`: verify the vinext build output
- `npm test`: build the starter and verify its rendered loading skeleton
